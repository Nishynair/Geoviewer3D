# Changelog

## 1.0.0 - 2026-10-04

- Establish the first stable npm contract with the `inspectGeoJSON` and
  `measureGeoJSONGeometry` functions and their TypeScript result types.
- Include structural validation, five deterministic coordinate diagnostic
  checks, dataset summaries, coordinate Z ranges, and selected geometry
  measurements.
- Publish built ECMAScript modules and TypeScript declarations for Node.js 20+
  and browser bundlers.
- Document measurement assumptions, diagnostic limits, and the precision
  heuristic in the README.
